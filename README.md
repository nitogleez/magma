# Magma

App de gimnasio para el móvil y el ordenador: rutinas editables, registro de entrenos, un entrenador que te dice qué peso y cuántas reps tocan, rangos por músculo, perfil y logros.

Abre **https://nitogleez.github.io/magma/**, pulsa *Continuar con Google* y añádela a la pantalla de inicio.

Cada persona guarda sus datos en una hoja "Magma · datos" de **su propio Google Drive**. La app solo tiene permiso para abrir los archivos que crea ella misma; este repositorio no guarda datos de nadie.
